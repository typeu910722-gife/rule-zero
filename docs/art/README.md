## 已採用進設定的細節
- **麻糬的空白名牌**：全鎮只有他的名牌是空的——忘得最徹底的人。
- **露露背後「藏起來的線頭」**：可以對她「拉線頭」（第二章起）。
- **鎮長的修理室鑰匙、名冊夾板、懷錶**：名冊在第五章揭露「47」。
- **Fen 的筆記本、地圖、鑰匙**：筆記本＝提示系統；鑰匙＝第二章的鐘塔鑰匙。
- **波波的「未寄出」信件**：第三章核心道具。
- **地圖新地點**：鏡之屋（第四章入口）、修理室（獨立建築）、河流與石橋、居民小屋、守則廣場。

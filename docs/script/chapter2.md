> 對應 GDD v0.3 第 6 節。v0.2：第二天、第三天、畢業典禮、結尾、壞結局的完整劇本；涅槃計畫與和平鴿的過去。

> ⚠ 本章含有對兒童（玩偶）的言語羞辱、電擊、肢體改造等場面，且以**玩家親手操作的遊戲**完整呈現。商店頁與章節開頭都要有內容警告。

### 0.1 本章寫作規則（補充第一章 0.1）
- **漂白鎮沒有疊字、沒有「喔～」。** 居民說話像在背書；只有私下、沒人在看的時候，才會露出原本的語氣。
- **和平鴿永遠溫柔。** 他不吼叫、不罵髒話。所有殘忍的話都用最溫柔的語氣說。
- **和平鴿的溫柔是演的。** 玩家要從細節察覺他在享受：他會數孩子哭了幾秒、聽到慘叫時頭會微微歪一下、沒人看的時候會哼歌。絕對不讓他自己說出「我喜歡」。
- **小遊戲的 UI 要可愛到不合理。** 星星評分、歡樂音效、「做得好！」的貼紙。殘忍的是內容，不是介面。
- **壞孩子是真的做過壞事。** 不替他們洗白。本章要讓玩家同時覺得「他們活該被罰」和「沒有人活該被這樣對待」。
- 修理場面**完整演出**，但血一律是棉花，傷口一律是縫線、破洞、褪色。

## 1. 前情：第二章怎麼開始

第一章結尾，小布在修理室被「縫起來」。第二章不回到棉花糖鎮：

- 縫線畫面拆開，小布醒在火車上。這次車廂裡還有**露露、麻糬、波波**，三個人都睡著。
- 每個人胸口都別著一張「**慈愛組織 轉介單**」。露露、麻糬、波波的單子寫著「模範生」，小布的寫著「**壞孩子**」。
- 車掌：「下一站——漂白鎮。這一站，要把顏色還回去。」

**真相（第二天夜晚的偷聽揭曉）**：
- 這班火車本來要開往慈愛綜合醫院，帶露露、麻糬、波波去「做檢查」。漂白鎮只是途經的一站。
- 和平鴿在漂白鎮攔下火車，威脅車掌：「帶隔壁鎮的孩子經過我的鎮，就要留一個下來『**校外參訪**』。不然——全部的人一起漂白。」
- 和平鴿親自挑了小布（他對「第 47 個」特別有興趣）。車掌為了保住其他人，點頭了。
- 小布的轉介單「壞孩子」三個字，是和平鴿在月台上當場寫上去的。所以筆跡和其他字不一樣。
- 這也讓結尾變成：小布離開漂白鎮，是車掌第一次違背和平鴿的條件（若刺向面具、鼬鼬切換軌道，則是硬闖）。

**分開安排**：
- 露露、麻糬、波波住在河對岸的「模範生宿舍」，被當成「矯正的榜樣」。漂白鎮的孩子每天都要隔著鐵絲網看他們笑。
- 小布和漂白鎮的六個居民住在一起。**跟河對岸的模範生說話違反守則。**
- 兩邊只在鐵絲網邊、點名廣場（模範生站在高台上）、畢業典禮見面。

## 2. 世界觀補充：慈愛組織與漂白鎮

> 以下是**隱藏真相**，遊戲裡不會直接說出，只能從照片、檔案、對話的縫隙拼出來。

- **慈愛組織**：表面上經營孤兒院、學校、醫院的慈善團體。徽章是「一顆被針穿過的心」。
- **漂白鎮**：慈愛組織的「矯正學校」。收容在學校霸凌別人的孩子。
- **矯正流程**：
  1. **反省**：言語羞辱、公開認罪。
  2. **治療**：電擊、漂白。
  3. **修剪**：把「壞的部分」從身體上剪下來。
  4. **畢業**：剩下的部分重新塞棉花，以「好孩子」的身分送到棉花糖鎮，從此什麼都不記得。
- **剪下來的「壞的部分」**不會消失，會變成一隻失去顏色的玩偶，留在漂白鎮當「樣品」。
- **修不好的孩子**會被「處分」：拆開，零件運到棉花糖鎮的森林。**第一章那座零件山，就是這裡送過去的。**

### 2.1 Fen 的雙色之謎
- Fen 在學校曾經霸凌「遙」（小布）。
- Fen 的父親希望兒子**保留記憶**，不想讓他像其他孩子一樣變成一張白紙；但他同時私下和慈愛組織做了交換條件：「**讓我的兒子變得更好**。」
- 結果：Fen 的記憶沒被塞掉，但他「壞的部分」被剪了下來。
  - 留在棉花糖鎮、有顏色、記得一切的 → **Fen**（所以他是唯一記得輪迴的人）。
  - 被剪下來、留在漂白鎮、臉色慘白的 → **白面**。
- Fen 一直保護小布，其實是贖罪。但他只留下了「要保護小布」的感覺，忘了**為什麼**。為什麼要保護小布的答案，在白面身上。

### 2.2 涅槃計畫：玩偶的肉身
- 所有玩偶（棉花糖鎮、漂白鎮）的**肉身都還活著**，躺在慈愛組織實驗醫院的「**涅槃計畫區**」，頭上接著很多條線。棉花糖鎮和漂白鎮，是他們的意識所在的地方。
- 「畢業」＝意識被重新塞棉花；醫院紀錄寫「生命徵象：穩定」。
- 「處分」（死亡）＝意識被拆散、零件丟進森林；醫院裡的身體繼續呼吸、心跳，但裡面是空的。紀錄寫「意識：已處分　身體：維持中」。
- 醫院裡不只一個計畫：隔壁棟「**比斯泰德**」有 **N.W. Project**（內容待定，之後章節）。
- 第二章只埋伏筆：嘎嘎燒壞一半的照片、和平鴿辦公室的夾板、月台上的偷聽、處分時遠方的「嗶——」、結尾廣播「涅槃計畫區」。第三章抵達醫院，倖存者會看見自己的身體。

### 2.3 和平鴿的過去
- 他以前也是漂白鎮的壞孩子，坐過治療室那張小椅子。
- 在被漂白的過程中，他看到了教官的電腦，發現這裡不是學校，是實驗。
- 某天晚上，他**反殺了當時的教官**，戴上那位教官的鴿子面具。**面具嘴喙的裂痕就是那一晚留下的。**
- 他沒有逃，反而向組織表現出絕對的忠誠，因此被高層吸收，成為新的教官。
- 「痛是愛」是他演給組織看的。真正的他是**徹頭徹尾的心理變態**：喜歡聽孩子叫，喜歡數他們哭了幾分鐘，最喜歡看他們「想起來的那一瞬間」的表情。
- 和車掌：見 2.4。

### 2.4 車掌的真實身分（第三章揭曉，本章只埋伏筆）
- 車掌是**當初決定吸收和平鴿的慈愛組織高層的弟弟**。
- 當年他極力反對：「讓那個孩子加入是錯誤的。」哥哥沒有聽。
- 和平鴿加入之後，漂白鎮的「畢業生」變了：以前的畢業生只是忘記，還保有自己的個性；之後的畢業生被漂得**沒有太多自己的思維**，不頂嘴、不問為什麼、不想要什麼——像行屍走肉，也就是**社會所期待的樣子**。組織高層對這個成果非常滿意。
- 這些畢業生被送到棉花糖鎮，和被他們霸凌過的孩子住在一起，雙方都不記得。棉花糖鎮裡那些「笑得特別空」的居民，就是這個時期之後的畢業生。
- 本章的伏筆：月台上的偷聽（和平鴿：「你那時候說我是『錯誤』」「你哥哥選了我」）、和平鴿叫車掌的舊名字被廣播蓋掉。

### 2.5 熊熊鎮長與輪迴
- 熊熊鎮長是**真的被做成了玩偶**。他的肉身已經不存在，不在涅槃計畫區裡。他是唯一一個「回不去」的人。
- 小布在棉花糖鎮一直輪迴，是因為熊熊鎮長：每次「修理」完，他都會把孩子送回**總部**，讓他從第一天重新來一次，**幫孩子忘得更乾淨**。他真心認為這是慈悲。
- 載孩子往返總部的，就是車掌的火車。從棉花糖鎮到總部的路線會經過漂白鎮。**和平鴿看著小布被載著經過了 47 次，這是第一次火車停下來。**
- 本章鎮長不登場。和平鴿提到他：「那隻熊太心軟了。他把孩子送回去重來，以為那樣是溫柔。」

### 2.6 糖果與記憶（貫穿後續章節的主線）
- 棉花糖鎮的糖果、漂白鎮的白色糖果，都是讓孩子「不用想那麼多」的東西。
- 露露、麻糬、波波這次會被送往醫院「做檢查」，是因為他們**最近沒有好好吃糖果**，開始出現「想起來」的徵兆。
- 在漂白鎮，模範生拒絕吃白色糖果，記憶恢復得更快。本章是**開始**，第三章之後會陸續崩潰。
- 核心糾結：他們想起來了——漂白鎮裡被虐待的孩子，**就是以前霸凌自己的人**。他們痛苦、恨，卻又不希望對方遭受這樣的對待。
  - 波波：小棘攔了他所有的信、造他的謠。但看到小棘被和平鴿抱住，他抓住了通電的鐵絲網。
  - 露露：等了一個禮拜的信箱，原來是被小棘偷走的。但畢業典禮上，她是第一個喊「不要」的人。
  - 小布：白面霸凌過「遙」。小布還沒想起來，但每次看到白面，胸口都會痛。（完整的糾結留到之後的章節）

## 3. 角色設定卡

### 3.1 漂白鎮的六個居民（不跟好孩子混在一起）

> 設計原則：六個人代表六種霸凌者。每個人都有一個「他做過的事」和一個「他為什麼變成這樣」。

#### ① 白面 — 臉色慘白的狐狸（Fen 的壞孩子回憶）
| 項目 | 內容 |
|---|---|
| 外表 | 和 Fen 一模一樣的體型，全身灰白，臉是紙一樣的慘白。連帽背心沒有補丁（Fen 的補丁是之後才縫的）。**沒有尾巴**，屁股上只剩一圈縫線。眼睛是兩顆黑鈕扣，比 Fen 的大一點 |
| 做過的事 | 帶頭霸凌遙。最常說的話：「是你自己活該。」 |
| 現在 | 他是「已經修好的樣品」，所以不會被修理。整天坐在宿舍屋頂冷眼旁觀，毒舌、什麼都知道、什麼都不在乎 |
| 對小布 | 第一眼就認出來：「喲。遙。你還活著啊。」小布不懂，白面也不解釋 |
| 秘密 | 他記得 Fen 忘掉的那一半：父親的交換條件、他對遙做過的每一件事。他嘴上說不在乎，但他也是**被丟下的那一半** |
| 台詞風格 | 短、冷、帶刺。偶爾一句話跟 Fen 一模一樣，讓玩家起雞皮疙瘩 |
| 命運 | 固定上車（第三章與 Fen 的「合體／對決」伏筆） |

#### ② 小棘 — 黑色刺蝟（麻糬在孤兒院的好朋友）
| 項目 | 內容 |
|---|---|
| 外表 | 黑色刺蝟，刺被剪得參差不齊。永遠掛著一個很標準的笑容。胸口別著「模範壞孩子」徽章 |
| 孤兒院 | 和麻糬在慈愛組織的孤兒院一起長大。小棘很會討大人喜歡，**被領養了四次，四次都被退回來**：「刺太多，會刺傷我們的孩子。」「他不親人。」「我們有自己的孩子了。」「他太會說謊。」麻糬一次都沒有被領養。每次小棘被退回來，麻糬都在門口等他 |
| 兩人的心結 | 麻糬羨慕小棘「至少有人要」；小棘羨慕麻糬「至少不會被丟掉」。兩個人都沒說出口 |
| 偽裝 | 被退回四次後學會：「只要一直笑、一直說對不起，就不會被丟掉。」漂白鎮最會道歉的人，也最常舉報別人。他用這種方法活下來 |
| 做過的事 | 在學校暗戀露露，但露露喜歡波波。小棘嫉妒，偷偷攔下波波寫給露露的每一封信，還在班上散播波波的謠言。**波波郵袋裡那些「未寄出」的信，就是從這裡開始的**：波波一直沒等到回信，以為露露不在乎他 |
| 秘密 | 只有他還記得麻糬的本名：**小滿**。（麻糬的名牌在第一章是空白的） |
| 命運 | 依玩家選擇（見 7.2） |

#### ③ 條碼 — 斑馬
| 項目 | 內容 |
|---|---|
| 外表 | 黑白斑馬，本來有十二條斑紋，現在剩**三條**。每被修理一次就被漂掉一條 |
| 做過的事 | 班上群組的管理員，負責「決定今天要討厭誰」 |
| 現在 | 說話越來越像廣播：「今天的天氣，很好。今天的我，很好。」偶爾會冒出一句原本的口頭禪：「欸你們知道嗎——」然後自己愣住 |
| 機制 | 斑紋數是看得見的倒數計時。玩家每天都會看到他少一條 |
| 命運 | **固定死亡**。第三天最後一條斑紋被漂掉，畢業典禮上「修不好」，被處分。本章第一個必然的失去 |

#### ④ 嘎嘎 — 烏鴉
| 項目 | 內容 |
|---|---|
| 外表 | 灰黑烏鴉，**嘴喙被縫起來**。一隻眼睛是舊相機的鏡頭 |
| 做過的事 | 霸凌的時候負責錄影、在旁邊哈哈大笑 |
| 現在 | 不能說話，只能比手語或寫字。他的相機眼還能拍照，裡面存著學校時期的照片 |
| 機制 | 相機是本章的**證據道具**：幫他做事可以換看一張照片。照片會揭露白面霸凌遙、小棘攔信、和平鴿不戴面具的側臉 |
| 命運 | 依玩家選擇 |

#### ⑤ 重重 — 河馬
| 項目 | 內容 |
|---|---|
| 外表 | 灰色大河馬，全鎮最大隻，身上縫線最多 |
| 做過的事 | 勒索、打人。在家裡被父親打 |
| 現在 | 被電最多次。聽到哨音就發抖、立正。不太說話，但會把自己的糖果分給小布 |
| 意義 | 讓「壞孩子也是受害者」最明顯的角色 |
| 命運 | 依玩家選擇。最可能為了保護別人而死 |

#### ⑥ 鼬鼬 — 灰色黃鼠狼
| 項目 | 內容 |
|---|---|
| 外表 | 細長的灰黃鼠狼，脖子上圍著一條偷來的（唯一有顏色的）紅毛線 |
| 做過的事 | 偷東西、作弊、賣考卷。全校最聰明 |
| 現在 | 一直在計畫逃跑。是本章的「Fen 角色」：帶小布偷溜、教他漂白鎮的規則怎麼繞過 |
| 台詞風格 | 嘴賤、講話很快，但從不說謊（「說謊要記住太多東西，我懶」） |
| 命運 | 依玩家選擇。逃跑計畫的成敗決定「上車」的人數 |

### 3.2 和平鴿（Boss／教官）
| 項目 | 內容 |
|---|---|
| 身分 | **人類**。代號「和平鴿」。慈愛組織派駐漂白鎮的教官 |
| 外表 | 戴著白色鴿子面具（陶瓷質感，嘴喙有一道裂痕），白色長大衣、白手套、聽診器、哨子。**他是本作第一個出現的人類**，比例比玩偶大很多，玩偶只到他的膝蓋 |
| 個性 | 永遠輕聲細語。每次電擊前都會先擁抱孩子：「乖孩子不痛。痛的是壞的那一半。」 |
| 信念 | 表面上：熊熊鎮長相信「遺忘是慈悲」，和平鴿說「痛是愛」。**實際上那是演給組織看的**；他是心理變態，以孩子的痛苦為樂，不恨他們也不愛他們，只是覺得「很好聽」 |

## 5. 系統

### 5.1 漂白鎮守則（公告欄，每天會變）
```
慈愛組織 漂白鎮 矯正守則
1. 說「對不起」，要說到老師滿意為止。
2. 不可以有顏色。
3. 不可以哭。眼淚會弄髒棉花。
4. 不可以和河對岸的模範生說話。
5. 舉報壞孩子的人，可以得到一顆糖。
6. 點名沒到的人，送去洗衣房。
7. 你做過的事，你自己最清楚。
```
- 第二天：第 3 條變成「不可以哭。**哭的人加倍。**」
- 第三天：多出第 8 條「畢業的孩子，不會再回來。」

### 5.2 操行成績單（第一章懷疑值的明牌版）
- 起始 **100 分**，隨時可在日記查看。違反守則、在小遊戲裡「手下留情」會扣分；舉報別人、拿滿分會加分。
- 低於 60：和平鴿開始「特別關心」你（他的對話變多、擁抱變多）。
- 低於 30：第三天的畢業典禮，小布會被放上治療台（壞結尾分支，劇情仍進第三章，但上車人數 −1）。
- **反向設計**：拿高分＝當一個好的加害者。成績單越漂亮，存活的人越少。

### 5.3 顏色碎片
- 散落在漂白鎮的一點點顏色：彩色鈕扣、一段毛線、一張彩色糖果紙。
- 撿起來＝保住一段記憶（解鎖夢境碎片）。但持有顏色違反第 2 條：晚上點名有機率被搜身（扣分）。
- 在「洗白白」小遊戲裡故意留下一塊顏色，等於幫那個居民保住一段記憶，影響他的存活。

### 5.4 膽量
沿用第一章：每天 2 點，睡覺回滿。本章主要用途：
- 違反守則（偷溜、跟模範生說話、藏顏色）
- 在小遊戲裡**手下留情**或**替別人受罰**

### 7.2 畢業典禮與存活判定

**畢業典禮**：和平鴿把針交到小布手上，要他對小棘「重新塞棉花」。

【選項】
- **照做**（操行分數高時預設選中）→ 小棘畢業：變成一個什麼都不記得的好孩子，被送往棉花糖鎮。麻糬在對岸看著他走過去，小棘對他笑，像看陌生人
- **把針刺向和平鴿的面具**（膽量-1，需要 ≥1）→ 面具的裂痕擴大，露出一點點人類的臉。觸發鼬鼬的逃跑計畫
- **把針交還給和平鴿**（什麼都不做）→ 和平鴿親自動手。小棘的結局依前面的選擇判定

**存活條件**（每個居民獨立判定）：

| 居民 | 存活（上車）條件 | 失敗時 |
|---|---|---|
| 白面 | 固定上車 | — |
| 條碼 | 固定死亡（處分） | 洗白白留色 → 死前說出一句完整的話：「欸你們知道嗎……我其實很怕一個人。」 |
| 小棘 | 修剪時留下最後一根刺，**且**反省會抽掉孤兒院的罪狀卡 | 只做到一個 → 畢業（被抹除，第三章不會出現，但之後章節可能在棉花糖鎮重逢）；都沒做 → 處分（死亡） |
| 重重 | 道歉練習時替他受罰，**或**搶椅子時代替他輸 | 搶椅子最後一輪進治療室，沒有回來（死亡） |
| 嘎嘎 | 找出壞孩子時**沒有**舉報他（且畢業典禮刺向面具，或和平鴿沒有親自動手） | 被舉報後送去「拆線」，嘴喙被拆開，卻再也說不出話；畢業 |
| 鼬鼬 | 找出壞孩子時沒有舉報他、第二天夜晚跟他偷溜，**且**畢業典禮刺向面具 | 逃跑計畫失敗，他一個人引開和平鴿，留在月台上（生死不明，第三章揭曉） |

- 膽量限制下，第一輪**不可能救下所有人**。刻意設計。
- 河對岸的露露、麻糬、波波固定上車（他們是「模範生」，被安排轉往醫院「做檢查」）。

# 第二章「漂白鎮」— 設計與劇本 v0.1

> 對應 GDD v0.3 第 6 節。本輪內容：本章設計、角色設定卡、小遊戲規格、序章＋第一天完整劇本、第二～三天大綱。

> ⚠ 本章含有對兒童（玩偶）的言語羞辱、電擊、肢體改造等場面，且以**玩家親手操作的遊戲**完整呈現。商店頁與章節開頭都要有內容警告。

| 項目 | 內容 |

### 0.1 本章寫作規則（補充第一章 0.1）
- **漂白鎮沒有疊字、沒有「喔～」。** 居民說話像在背書；只有私下、沒人在看的時候，才會露出原本的語氣。
- **和平鴿永遠溫柔。** 他不吼叫、不罵髒話。所有殘忍的話都用最溫柔的語氣說。
- **小遊戲的 UI 要可愛到不合理。** 星星評分、歡樂音效、「做得好！」的貼紙。殘忍的是內容，不是介面。
- **壞孩子是真的做過壞事。** 不替他們洗白。本章要讓玩家同時覺得「他們活該被罰」和「沒有人活該被這樣對待」。
- 修理場面**完整演出**，但血一律是棉花，傷口一律是縫線、破洞、褪色。

## 1. 前情：第二章怎麼開始

第一章結尾，小布在修理室被「縫起來」。第二章不回到棉花糖鎮：

- 縫線畫面拆開，小布醒在火車上。這次車廂裡還有**露露、麻糬、波波**，三個人都睡著。
- 每個人胸口都別著一張「**慈愛組織 轉介單**」。露露、麻糬、波波的單子寫著「模範生」，小布的寫著「**壞孩子**」。
- 車掌：「下一站——漂白鎮。這一站，要把顏色還回去。」

**分開安排**：
- 露露、麻糬、波波住在河對岸的「模範生宿舍」，被當成「矯正的榜樣」。漂白鎮的孩子每天都要隔著鐵絲網看他們笑。
- 小布和漂白鎮的六個居民住在一起。**跟河對岸的模範生說話違反守則。**
- 兩邊只在鐵絲網邊、點名廣場（模範生站在高台上）、畢業典禮見面。

## 2. 世界觀補充：慈愛組織與漂白鎮

> 以下是**隱藏真相**，遊戲裡不會直接說出，只能從照片、檔案、對話的縫隙拼出來。

- **慈愛組織**：表面上經營孤兒院、學校、醫院的慈善團體。徽章是「一顆被針穿過的心」。
- **漂白鎮**：慈愛組織的「矯正學校」。收容在學校霸凌別人的孩子。
- **矯正流程**：
  1. **反省**：言語羞辱、公開認罪。
  2. **治療**：電擊、漂白。
  3. **修剪**：把「壞的部分」從身體上剪下來。
  4. **畢業**：剩下的部分重新塞棉花，以「好孩子」的身分送到棉花糖鎮，從此什麼都不記得。
- **剪下來的「壞的部分」**不會消失，會變成一隻失去顏色的玩偶，留在漂白鎮當「樣品」。
- **修不好的孩子**會被「處分」：拆開，零件運到棉花糖鎮的森林。**第一章那座零件山，就是這裡送過去的。**

### 2.1 Fen 的雙色之謎
- Fen 在學校曾經霸凌「遙」（小布）。
- Fen 的父親希望兒子**保留記憶**，不想讓他像其他孩子一樣變成一張白紙；但他同時私下和慈愛組織做了交換條件：「**讓我的兒子變得更好**。」
- 結果：Fen 的記憶沒被塞掉，但他「壞的部分」被剪了下來。
  - 留在棉花糖鎮、有顏色、記得一切的 → **Fen**（所以他是唯一記得輪迴的人）。
  - 被剪下來、留在漂白鎮、臉色慘白的 → **白面**。
- Fen 一直保護小布，其實是贖罪。但他只留下了「要保護小布」的感覺，忘了**為什麼**。為什麼要保護小布的答案，在白面身上。

## 3. 角色設定卡

### 3.1 漂白鎮的六個居民（不跟好孩子混在一起）

> 設計原則：六個人代表六種霸凌者。每個人都有一個「他做過的事」和一個「他為什麼變成這樣」。

#### ① 白面 — 臉色慘白的狐狸（Fen 的壞孩子回憶）
| 項目 | 內容 |
|---|---|
| 外表 | 和 Fen 一模一樣的體型，全身灰白，臉是紙一樣的慘白。連帽背心沒有補丁（Fen 的補丁是之後才縫的）。**沒有尾巴**，屁股上只剩一圈縫線。眼睛是兩顆黑鈕扣，比 Fen 的大一點 |
| 做過的事 | 帶頭霸凌遙。最常說的話：「是你自己活該。」 |
| 現在 | 他是「已經修好的樣品」，所以不會被修理。整天坐在宿舍屋頂冷眼旁觀，毒舌、什麼都知道、什麼都不在乎 |
| 對小布 | 第一眼就認出來：「喲。遙。你還活著啊。」小布不懂，白面也不解釋 |
| 秘密 | 他記得 Fen 忘掉的那一半：父親的交換條件、他對遙做過的每一件事。他嘴上說不在乎，但他也是**被丟下的那一半** |
| 台詞風格 | 短、冷、帶刺。偶爾一句話跟 Fen 一模一樣，讓玩家起雞皮疙瘩 |
| 命運 | 固定上車（第三章與 Fen 的「合體／對決」伏筆） |

#### ② 小棘 — 黑色刺蝟（麻糬在孤兒院的好朋友）
| 項目 | 內容 |
|---|---|
| 外表 | 黑色刺蝟，刺被剪得參差不齊。永遠掛著一個很標準的笑容。胸口別著「模範壞孩子」徽章 |
| 孤兒院 | 和麻糬在慈愛組織的孤兒院一起長大。小棘很會討大人喜歡，**被領養了四次，四次都被退回來**：「刺太多，會刺傷我們的孩子。」「他不親人。」「我們有自己的孩子了。」「他太會說謊。」麻糬一次都沒有被領養。每次小棘被退回來，麻糬都在門口等他 |
| 兩人的心結 | 麻糬羨慕小棘「至少有人要」；小棘羨慕麻糬「至少不會被丟掉」。兩個人都沒說出口 |
| 偽裝 | 被退回四次後學會：「只要一直笑、一直說對不起，就不會被丟掉。」漂白鎮最會道歉的人，也最常舉報別人。他用這種方法活下來 |
| 做過的事 | 在學校暗戀露露，但露露喜歡波波。小棘嫉妒，偷偷攔下波波寫給露露的每一封信，還在班上散播波波的謠言。**波波郵袋裡那些「未寄出」的信，就是從這裡開始的**：波波一直沒等到回信，以為露露不在乎他 |
| 秘密 | 只有他還記得麻糬的本名：**小滿**。（麻糬的名牌在第一章是空白的） |
| 命運 | 依玩家選擇（見 7.2） |

#### ③ 條碼 — 斑馬
| 項目 | 內容 |
|---|---|
| 外表 | 黑白斑馬，本來有十二條斑紋，現在剩**三條**。每被修理一次就被漂掉一條 |
| 做過的事 | 班上群組的管理員，負責「決定今天要討厭誰」 |
| 現在 | 說話越來越像廣播：「今天的天氣，很好。今天的我，很好。」偶爾會冒出一句原本的口頭禪：「欸你們知道嗎——」然後自己愣住 |
| 機制 | 斑紋數是看得見的倒數計時。玩家每天都會看到他少一條 |
| 命運 | **固定死亡**。第三天最後一條斑紋被漂掉，畢業典禮上「修不好」，被處分。本章第一個必然的失去 |

#### ④ 嘎嘎 — 烏鴉
| 項目 | 內容 |
|---|---|
| 外表 | 灰黑烏鴉，**嘴喙被縫起來**。一隻眼睛是舊相機的鏡頭 |
| 做過的事 | 霸凌的時候負責錄影、在旁邊哈哈大笑 |
| 現在 | 不能說話，只能比手語或寫字。他的相機眼還能拍照，裡面存著學校時期的照片 |
| 機制 | 相機是本章的**證據道具**：幫他做事可以換看一張照片。照片會揭露白面霸凌遙、小棘攔信、和平鴿不戴面具的側臉 |
| 命運 | 依玩家選擇 |

#### ⑤ 重重 — 河馬
| 項目 | 內容 |
|---|---|
| 外表 | 灰色大河馬，全鎮最大隻，身上縫線最多 |
| 做過的事 | 勒索、打人。在家裡被父親打 |
| 現在 | 被電最多次。聽到哨音就發抖、立正。不太說話，但會把自己的糖果分給小布 |
| 意義 | 讓「壞孩子也是受害者」最明顯的角色 |
| 命運 | 依玩家選擇。最可能為了保護別人而死 |

#### ⑥ 鼬鼬 — 灰色黃鼠狼
| 項目 | 內容 |
|---|---|
| 外表 | 細長的灰黃鼠狼，脖子上圍著一條偷來的（唯一有顏色的）紅毛線 |
| 做過的事 | 偷東西、作弊、賣考卷。全校最聰明 |
| 現在 | 一直在計畫逃跑。是本章的「Fen 角色」：帶小布偷溜、教他漂白鎮的規則怎麼繞過 |
| 台詞風格 | 嘴賤、講話很快，但從不說謊（「說謊要記住太多東西，我懶」） |
| 命運 | 依玩家選擇。逃跑計畫的成敗決定「上車」的人數 |

### 3.2 和平鴿（Boss／教官）
| 項目 | 內容 |
|---|---|
| 身分 | **人類**。代號「和平鴿」。慈愛組織派駐漂白鎮的教官 |
| 外表 | 戴著白色鴿子面具（陶瓷質感，嘴喙有一道裂痕），白色長大衣、白手套、聽診器、哨子。**他是本作第一個出現的人類**，比例比玩偶大很多，玩偶只到他的膝蓋 |
| 個性 | 永遠輕聲細語。每次電擊前都會先擁抱孩子：「乖孩子不痛。痛的是壞的那一半。」 |
| 信念 | 熊熊鎮長相信「遺忘是慈悲」；**和平鴿相信「痛是愛」**。他真心覺得自己在拯救孩子 |
| 和車掌 | **兩個人認識**。第二天夜晚的偷聽場景：「你又帶他來了。」「這次不一樣。」「你每次都這樣說。」和平鴿會叫車掌一個**舊的名字**（被廣播聲蓋過去）。真正的關係留給第三章 |
| 弱點伏筆 | 面具的裂痕。嘎嘎的照片裡有一張他不戴面具的側臉，很年輕 |

## 5. 系統

### 5.1 漂白鎮守則（公告欄，每天會變）
```
慈愛組織 漂白鎮 矯正守則
1. 說「對不起」，要說到老師滿意為止。
2. 不可以有顏色。
3. 不可以哭。眼淚會弄髒棉花。
4. 不可以和河對岸的模範生說話。
5. 舉報壞孩子的人，可以得到一顆糖。
6. 點名沒到的人，送去洗衣房。
7. 你做過的事，你自己最清楚。
```
- 第二天：第 3 條變成「不可以哭。**哭的人加倍。**」
- 第三天：多出第 8 條「畢業的孩子，不會再回來。」

### 5.2 操行成績單（第一章懷疑值的明牌版）
- 起始 **100 分**，隨時可在日記查看。違反守則、在小遊戲裡「手下留情」會扣分；舉報別人、拿滿分會加分。
- 低於 60：和平鴿開始「特別關心」你（他的對話變多、擁抱變多）。
- 低於 30：第三天的畢業典禮，小布會被放上治療台（壞結尾分支，劇情仍進第三章，但上車人數 −1）。
- **反向設計**：拿高分＝當一個好的加害者。成績單越漂亮，存活的人越少。

### 5.3 顏色碎片
- 散落在漂白鎮的一點點顏色：彩色鈕扣、一段毛線、一張彩色糖果紙。
- 撿起來＝保住一段記憶（解鎖夢境碎片）。但持有顏色違反第 2 條：晚上點名有機率被搜身（扣分）。
- 在「洗白白」小遊戲裡故意留下一塊顏色，等於幫那個居民保住一段記憶，影響他的存活。

### 5.4 膽量
沿用第一章：每天 2 點，睡覺回滿。本章主要用途：
- 違反守則（偷溜、跟模範生說話、藏顏色）
- 在小遊戲裡**手下留情**或**替別人受罰**

## 6. 小遊戲規格（矯正就是遊戲）

> 原則：每一個「修理」都由玩家親手操作。UI 永遠是可愛的。每個小遊戲都有一個「不照規則玩」的隱藏選擇，需要膽量或會扣操行分數。

| # | 名稱 | 出現 | 玩法 | 殘忍的地方 | 隱藏選擇 |
|---|---|---|---|---|---|
| 1 | **道歉練習** | 第一天（教學） | 節奏遊戲：跟著音樂盒拍子按出「對、不、起」三個字 | 畫面角落的「愛心電量計」就是電壓。**按錯時被電的不是小布，是排在旁邊的重重**。重重被電時整個身體彈起來，棉花從縫線冒出細煙 | 故意全按錯，讓電量計爆表 → 和平鴿把電擊轉到小布身上（膽量-1），重重記住你 |
| 2 | **洗白白** | 第二天 | 洗衣房：用刷子把玩偶身上的顏色刷掉，刷越乾淨星星越多 | 對象是**條碼**，刷的是他的斑紋。刷的時候他會小聲說原本的口頭禪，越刷越聽不清楚 | 故意留一塊沒刷 → 條碼保住一段記憶（但他仍然會死，只是死前會說出一句完整的話）。扣操行分數 |
| 3 | **找出壞孩子** | 第二天 | 一排長得一模一樣的灰色玩偶，找出「笑得不標準」的那一個（找不同） | 找到的那隻會被帶走。**每一輪都是一個你認識的居民** | 不舉報（膽量-1）。舉報可以拿到糖果和操行分數 |
| 4 | **反省會** | 第三天 | 小棘被綁在講台中央。玩家拿到一疊「罪狀卡」，要在時限內念給全班聽。每念一張，小棘的顏色就少一點，全班跟著喊「壞孩子！」 | 罪狀卡寫的是小棘真的做過的事（攔信、造謠），**也有他在孤兒院被大人說過的話**（「刺太多」「沒人要」）。念到那幾張，小棘的笑容第一次掉下來 | 抽掉孤兒院的那幾張不念（膽量-1，扣分） |

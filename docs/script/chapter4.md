## 1. 開場：槍聲之後（使用者決定 2026-10-20：和平鴿自縊，引出車掌的哥哥）

> ⚠ 自殺場面：只用影子與聲音，不呈現細節。`[gentle]` 時只留黑畫面與一句旁白。內容警告要標明。

*黑畫面。耳鳴。*
*很久以後，有東西慢慢地、規律地，發出「吱——吱——」的聲音。像繩子在晃。*
*燈亮著。*
*車掌手上的繩子斷了——槍打斷的是繩子。他低頭看著自己的手。*
*地上一把槍。*
*牆上，一個很長的影子，在晃。*
*你沒有抬頭。你不敢。*
*只看到地板上，一雙白色的鞋子，離地很高。*
*一根白色的羽毛，慢慢飄到你面前。*
**車掌**：……不要看。
*他站起來，擋在孩子們和那面牆之間。跟第三章月台上一模一樣。*

*實驗室的門開了。*
*一個很高的人走進來。白色的大衣、白手套。肩膀上，停著一隻**老鷹**。*
*他看了牆上一眼。只看了一眼。*
**理事**：……真可惜。他是最好的教官。
*車掌的背繃緊了。*
**車掌**：哥。
**理事**：好久不見。你還在開那班車啊。
*理事彎下腰，看著你們。他的眼睛很溫柔。比和平鴿還溫柔。*
**理事**：孩子們，嚇到了吧？沒事了。
**理事**：老師不在了，那就由我來上課。
*他按下牆上的開關。實驗室中央的機器亮起來。病床上的線，一條一條接到你們身上。*
**理事**：今天的課程是——三年二班。

### 1.1 車掌的哥哥（理事）支線（使用者：由這裡引出）
- 理事＝慈愛組織高層、車掌的哥哥、和老鷹溝通。當年**選了和平鴿**的人。
- 和平鴿真的是自縊嗎？本章只留疑點，不回答：
  - 槍打斷的是車掌的繩子，不是和平鴿——開槍的人想放走車掌？
  - 和平鴿的面具掉在地上，**嘴喙的裂痕多了一道**（第二章：裂痕是他反殺教官那一晚留下的）。
  - 窗台上的白鴿全部不見了。只剩一根褐色的大羽毛（老鷹的）。
- 理事在本章取代和平鴿的位置：上課、記錄、遞糖果。他不殘忍——他**相信這是對的**，這比和平鴿更可怕。
- 支線走向（建議，終章回收）：理事為了「成果」犧牲了和平鴿（和平鴿越來越失控，成果開始崩壞——第三章失控區就是證據）；車掌第一次和哥哥正面對立。

## 2. 結構

本章是一連串「視角」。每個視角＝一個人在**那一天之前或當天**的一段記憶，玩家用那個人的身體走（尺寸是人類，但手是布的——記憶和現在疊在一起）。

| 段落 | 視角 | 對應時間線（`story.md` 1.3） | 玩法 | 看到的新東西 |
|---|---|---|---|---|
| 4-1 | 遙（第一次） | 1 轉學、2 班規 | 探索教室、自我介紹 | 教室後面的班規＝棉花糖鎮守則；導師說「不會有人受傷」 |
| 4-2 | 小滿 | 3 被欺負、沒有人來找他 | 放學後的教室，一個人等 | 沒有人來接；辛禾來了（孤兒院） |
| 4-3 | 薙文 | 4 群組「決定今天要討厭誰」 | 手機介面：一則一則訊息滑過去（訊息內容看不清楚，只看到大家按的讚越來越多） | 名字被打上去的那一刻：「遙」 |
| 4-4 | 希露飛 | 5 綽號、鏡子 | 走廊被盯著看；回家，鏡子 | 鏡子碎片翻過去（第一章露露的房間） |

## 3. 那一天（4-9）

### 3.1 視角順序
| # | 視角 | 位置 | 玩家看到／聽到 |
|---|---|---|---|
| ① | 遙 | 校門口 → 走廊 | 學校放假，很安靜。遙穿著自己喜歡的小裙子，手裡握著一個粉紅色髮夾，一路練習要跟芬說的話（文字框是遙心裡的聲音：「對不起。」「那天的話，你可以忘掉。」）。走到廁所前，有人從後面叫了他的名字。**畫面停在廁所的門關上的那一刻。** |
| ② | 值日生（小狗居民） | 教室窗邊 | 他在擦窗戶。從窗戶看得到廁所的門。門被卡住。裡面有人在敲。他低下頭，繼續擦。（不呈現門內；只有隔著門的聲音，見 6.2） |
| ③ | 秋歌 | 廁所門外的走廊 | 他手上的手機在錄。畫面是手機的取景框，**取景框裡只有門板**。他的手在抖。 |
| ④ | 把風的人（輪流） | 廁所門外 | 每一個霸凌者的視角都會輪到一次「站在門外」：同一扇門、同一段走廊，只是換了一雙鞋。玩家連續幾次走到同一個位置，才發現**每個人都站過這裡**。畫面只有門、鞋子、走廊；聲音只到門外聽得到的程度（6.2） |
| ⑤ | 芬 | 三年二班教室 → 走廊 → 廁所前的樓梯 | 芬在教室讀書。聽到哭喊聲。他跑去找導師。導師跟著他走到走廊——在盡頭停住了，發抖，沒有走過去。芬一個人跑向廁所。在廁所前的樓梯口，他擋在門前。**窗外，一隻白鴿停在欄杆上，看著他。** |
| ⑥ | 郡主 | 廁所前 | 郡主站在芬的對面。他舉起手——**沒有碰到芬**。白鴿從窗外衝進來，撞在芬的胸口。芬往後倒，滾下樓梯。郡主的手還舉在半空中。所有人看到的，是那隻手。 |
| ⑦ | 導師 | 走廊盡頭 | 他看到芬摔下去。他看到大家看著郡主。他看到窗外的白鴿飛走了。他什麼都沒有說。（第一章結尾鎮長：「那天，老師沒有走過去。」） |
| ⑧ | 李恩 | 樓下 | 他第一個打電話報警。電話那頭的人問：「發生什麼事？」他說：「……有人掉下去了。」他沒有說，還有一個人在廁所裡。 |
| ⑨ | 遙（第二次） | 廁所裡 → 地板 | **畫面全黑**。只有水聲慢慢停下來。一聲髮夾掉在磁磚上。很久以後，遠處的警笛聲。 |

### 3.2 拼圖
- 視角 ⑤⑥⑦ 都看得到窗外的白鴿；只要玩家在三個視角裡都「看」過窗外（調查），日記會寫下：「推下芬的，不是郡主。」{c4_dove_seen}
- 若重重在第三章說過「我沒有推他」{c3_zhongzhong_innocent}，這裡會多一段：回到實驗室，重重哭了。第一次，有人相信他。

## 5. 回到實驗室

- 每看完一個視角，就回到實驗室幾秒：理事在旁邊看你的表情，在筆記本上記一筆。牆上的影子一直在晃，沒有人去看。
- 同伴們也在各自的病床上「看」自己的視角；回來的時候，每個人的表情都不一樣（立繪換成「想起來」的版本）。
- 白面在 4-8 之後，第一次叫了芬的名字：「……芬。」Fen 沒有回答，但他沒有把頭轉開。

## 6. 描寫原則與聲音設計

### 6.1 原則（`docs/story.md` 1.3）
- 廁所裡的事：**畫面、文字都不呈現**，只用隔著門的聲音暗示；畫面永遠在門外。
- 不把遙的身分、穿著、告白寫成原因或罪；錯的是霸凌的人。
- 遊戲文字裡不出現歧視用語、不出現「性霸凌」等字眼。
- `[gentle]`：只留畫面與一聲關門。

### 6.2 「那一天」的聲音清單（只用門外聽得到的程度）
| 可以用 | 用在哪裡 |
|---|---|
| 門被撞的悶響 | 視角 ② ③ |
| 門把被壓住、轉不動的喀喀聲 | 視角 ② |
| 很多人的笑聲（隔著門，悶悶的） | 視角 ② ③ |
| 水龍頭、水聲 | 視角 ③ ⑨ |
| 手機錄影的提示音 | 視角 ③ |
| 被摀住的哭喊（短，一次） | 視角 ⑤（芬聽到的） |
| 髮夾掉在磁磚上 | 視角 ⑨ |
| 白鴿振翅 | 視角 ⑤ ⑥ |
| 遠處的警笛 | 視角 ⑧ ⑨ |

**不可以用**：任何身體、衣物、性相關的聲音或台詞。

## 8. 最後的選擇（4-11）

*所有視角看完。實驗室。*
*理事把一顆白色的糖果，放在小布的手心。*
**理事**：全部都想起來了吧？很痛吧？
**理事**：吃下去，就不痛了。你們可以回到棉花糖鎮。那裡的燈還亮著，鐘也還在敲——有人一直替你們顧著。
*（棉花糖鎮的那隻烏鴉，車掌的眼睛。理事一直都知道。）*
*Fen 在旁邊的病床上。他伸出手。*
